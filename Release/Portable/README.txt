UNCENSORED STUDIO - PRODUCTION RELEASE v1.0.0
================================================================================

Welcome to Uncensored Studio — the 100% private, local AI creative writing & social suite.

HOW TO INSTALL / USE:

OPTION 1: MODERN INSTALLER (RECOMMENDED)
----------------------------------------
Double-click: UncensoredStudio-Installer.exe
Follow the on-screen setup wizard to install Uncensored Studio to your PC,
create desktop shortcuts, and auto-detect your GPU accelerator.

OPTION 2: CLASSIC INSTALLER
---------------------------
Double-click: UncensoredStudio-v1.0.0-Setup.exe
Standard Windows setup wizard.

OPTION 3: PORTABLE EDITION (NO INSTALLATION REQUIRED)
-----------------------------------------------------
Open the "Portable" folder and double-click "UncensoredStudio.exe" or "LaunchStudio.bat".
Everything runs directly from that folder without touching the Windows Registry.

================================================================================
HARDWARE & SYSTEM REQUIREMENTS:
- Operating System: Windows 10 / 11 (64-bit)
- RAM: 16 GB+ recommended
- GPU: AMD Radeon (Vulkan), NVIDIA GeForce (CUDA), Intel Arc, or multi-core CPU.
- 100% Offline & Private: Zero telemetry or cloud transmissions.
