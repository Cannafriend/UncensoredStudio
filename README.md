## 🌟 Key Features

### 1. 📖 Story & Novel Studio
- **Multi-Chapter Manuscript Organizer**: Manage entire novels across chapters with instant word counts and status indicators.
- **AI Prose Co-Author Toolbar**:
  - `⚡ Continue Story`: Generates the natural next 2–4 paragraphs with vivid sensory detail.
  - `🔥 Add Sensory / Heat`: Deepens physical sensations, tactile touch, heat, breath, and psychological tension.
  - `💬 Sharpen Dialogue`: Adds flirtatious banter, cadence, and expressive body language.
  - `✍️ Deepen Setting`: Enhances atmospheric lighting, visceral mood, and environment.
  - `💡 Brainstorm Next Beats`: Generates 4 distinct, compelling narrative branches.
- **Scene-Aware Lorebook Inspector**: Automatically scans chapter text and shows which characters/places are active in context.
- **1-Click Markdown Export**: Export chapters or full novels instantly.

### 2. 💬 Strictly Isolated Multi-Chat & Roleplay
- **Zero Memory Bleed**: Every conversation is strictly partitioned in local SQLite database storage.
- **Dynamic Author's Note Injection**: Injects customizable stylistic directions at configurable context depths.
- **Streaming Tokens**: Real-time token streaming with instant Re-roll, Continue, and Stop controls.

### 3. 🐦 X / Twitter Smut & Micro-Fiction Suite
- **Spicy Social Post Generator**:
  - `Micro-Smut / Drabbles`: 100–260 character standalone spicy vignettes.
  - `Chapter Teasers & Hooks`: Extracts irresistible cliffhangers from manuscript scenes.
  - `Multi-Tweet Threads`: Auto-formats numbered threads (`1/3`, `2/3`, `3/3`) with 1-click clipboard copy.
- **Live 280-Character Counter**: Color-coded limit indicator badges.

### 4. 📚 Lorebook & World Bible Engine
- **Entity Management**: Characters, Locations, Tropes/Kinks, Lore, and Relationship Dynamics.
- **Smart Keyword Triggering**: Automatically injects lore into prompt context only when triggered by relevant keywords.

### 5. ⚙️ Hardware Acceleration Engine
- **Vulkan / CUDA Backend**: Bundled with KoboldCPP Vulkan running 100% locally on your discrete GPU.
- **Model Support**: Built for high-capacity unaligned instruction models including **Magnum-12B-v2** and **L3-8B-Stheno-v3.2**.
